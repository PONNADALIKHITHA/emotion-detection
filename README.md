# Emotion Detection from Text

Detects 6 emotions (sadness, joy, love, anger, fear, surprise) using the `dair-ai/emotion` dataset.

## Setup
    python -m pip install -r requirements.txt

## Run the Streamlit app
    streamlit run streamlit_app.py

The app uses `baseline_model.joblib`. It is included in the repository and is generated by `baseline.py` if you need to rebuild it.

## Train the models
Install the larger training dependencies separately:

    python -m pip install -r training-requirements.txt
    python baseline.py
    python train_transformer.py
    python predict.py "I am so excited about tomorrow!"
    python app.py                 # optional Flask app at http://127.0.0.1:5000

## Deploy on Streamlit Community Cloud
1. Push this repository to GitHub.
2. In Streamlit Community Cloud, create an app from `PONNADALIKHITHA/emotion-detection`, branch `main`, and file `streamlit_app.py`.
3. Deploy. The cloud app uses the committed baseline model; the larger transformer checkpoints are kept out of Git.
